RunPod かんたん画像生成

RunPodのComfyUIを、ノードを触らずにフォームだけで使えます。各設定の下に「どのくらいが良いか」の目安が出ます。

使い方 接続 生成 履歴 困ったとき

はじめに：使い方
  1. RunPodで ComfyUI のテンプレートを選んでPodを Deploy します。
  2. Podが「Running」になったら Connect を押します。
  3. ポート 8188（HTTP Service）のURLをコピーします。
    例：https://abc123xyz-8188.proxy.runpod.net
  4. 下の「1. 接続」にURL（またはPod ID）を貼って 接続テスト を押します。
  5. モデルを選び、プロンプトを書いて 生成。迷ったらプリセット「まずはこれ（おすすめ）」を押してください。
  • Podを止めると課金が止まります。使い終わったらRunPodの画面でStop（またはTerminate）してください。Stopでも保存領域（ディスク）の料金は少しかかり、Terminateすると Pod上の画像も消えます。
  • PodのURLは秘密扱いに。URLを知っている人は誰でもあなたのPod（GPU）を使えてしまいます。人に見せたり、SNSに貼ったりしないでください。
  • パスワードは保存されません。接続情報はこのアプリのサーバーのメモリ上だけに置かれ、ファイルにもブラウザにも保存されません（サーバーを止めると消えます）。

1. 接続

RunPodの「Connect」に出るポート8188のURLを貼ります。Pod IDだけでもOK（自動で8188のURLにします）。

ユーザー名・パスワード（Podに認証をかけている場合のみ）

ここに入れた値は保存されません。ページを開き直したら入れ直してください。

2. 生成の設定

プリセット（押すと下の設定がまとめて変わります）

サイズ（幅×高さ）

画像はPodの中に保存されています。Podを削除（Terminate）すると消えるので、気に入った画像は「ダウンロード」で手元に保存してください。

3. 履歴（最新20件）

履歴に残るのは設定と画像の「場所」だけです。画像そのものはPod上にあり、Podを削除すると消えます。残したい画像はダウンロードしてください。項目を押すと、その時の設定（シード含む）がフォームに戻ります。

    困ったとき

    こんなときこうする
    ぼやける・粗いStepsとサイズを上げる（Steps 25前後、サイズ1024前後）
    指示が通らないCFGを上げる（5→7くらい）。大事な語をプロンプトの前のほうに書く
    色がギラギラ・焦げたようCFGを下げる（5前後に戻す）
    人物が2人になる・体が伸びるサイズを1024前後に戻す
    遅いStepsとサイズを下げる（枚数も1枚に）
    • 「接続できません」：Podが Running か、URLがポート8188のものか確認。起動直後は数分待ってから再試行。
    • 「モデルが見つかりません」：「再読み込み」を押して、一覧から選び直してください。
    • 「VRAMが足りません」：サイズか枚数を下げてください。
    • 最初の1枚はモデルの読み込みで時間がかかります（数十秒〜数分）。2枚目からは速くなります。

    このアプリは自分のPCで個人的に使うためのものです。PodのURLは他人に教えないでください。
