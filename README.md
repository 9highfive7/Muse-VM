# Muse-VM

シロ（Muse）のVMで進めるコードプロジェクトを、フォルダで分けて管理するモノレポです。
許可されたコネクターはこのリポジトリのみで、プロジェクトごとにフォルダを切って使います。

## プロジェクト一覧

| フォルダ | 内容 | 状態 |
|---|---|---|
| `runpod-image-app/` | RunPod + ComfyUI をノードなしで使う画像生成（関連作業用） | 準備中 |
| `experiments/` | 実験・使い捨てコード | 随時 |
| `_template/` | 新規プロジェクトの雛形 | - |

## 運用ルール

- 新しいプロジェクトは `_template/` をコピーしてフォルダを作り、この一覧へ1行追加する
- プロジェクトごとに `README.md` を置き、目的・動かし方・状態を書く
- 秘密情報（パスワード、APIキー、トークン）は絶対に置かない
- 大きく育ったプロジェクトは、必要になったら独立リポジトリへ切り出す
